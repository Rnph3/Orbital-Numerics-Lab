# P08 Orbital Numerics Lab — 물리학이 수치해석과 만날 때

## 0. 1분 요약

**만든 것:** 지구처럼 중심 천체를 도는 가상 물체의 운동을 Euler, Velocity Verlet, RK4라는 세 가지 수치적분 방법으로 계산하고, 에너지와 각운동량이 얼마나 보존되는지 비교했다.

**왜:** 물리 법칙이 정확해도 컴퓨터 계산 방법이 나쁘면 물체가 실제로는 얻지 않은 에너지를 얻는 것처럼 보일 수 있다. 과학 소프트웨어는 **방정식 구현 + 수치오차 평가**를 함께 해야 한다.

**실험:** 무차원 단위에서 원 궤도 한 바퀴, 160스텝. 테스트 18개 통과. 실제 인공위성 추적 데이터가 아니다.

## 1. '물리학을 컴퓨터에 넣는다'는 뜻

뉴턴의 법칙은 위치·속도의 시간 변화를 미분방정식으로 알려준다. 예를 들어 위치를 `(x,y)`, 속도를 `(vx,vy)`라 하면:

- `dx/dt = vx`, `dy/dt = vy`
- `dvx/dt = -μ*x/r³`, `dvy/dt = -μ*y/r³`
- `r = sqrt(x²+y²)`

이는 중심력에 대한 **이상화된 2체 문제의 시험입자 모델**이다. 실제 우주에는 다른 천체의 중력, 공기저항, 추진력, 궤도 불균일성이 있지만 이번 프로젝트는 전부 제외했다.

## 2. 왜 무차원 단위를 쓰나?

학습을 위해 중력 파라미터 `μ=1`, 시작 거리 `r=1`, 시작 속력 `v=1`로 정했다. 그러면 원 궤도 주기가 `T=2π`가 된다. 숫자가 작아지고 단위 변환 없이 계산기의 수치오차에 집중할 수 있다.

시작 상태: `(x,y,vx,vy)=(1,0,0,1)`.

물리학적 불변량:

- **단위 질량당 에너지:** `E=(vx²+vy²)/2 - μ/r`. 원 궤도에서는 시작 에너지 `E=-0.5`.
- **면 밖 각운동량:** `h=x*vy-y*vx`. 시작 `h=1`.

외부 힘·토크가 없는 이상화된 물리 모델에서는 이러한 값이 시간에 따라 일정하다. 코드가 멀리 어긋나면 수치오차를 의심해야 한다.

## 3. 세 가지 계산 방법

**Euler(오일러):** `새 위치 = 이전 위치 + dt·현재 속도` 식으로 현재 기울기만 사용한다. 매우 단순하지만 작은 오차가 반복 누적되기 쉽다.

**Velocity Verlet:** 위치는 기존 속도와 가속도로 먼저 이동시키고, 새 위치에서 계산한 가속도와 이전 가속도를 평균하여 속도를 갱신한다. 보존계의 기하 구조를 다루는 심플렉틱(symplectic) 성질과 시간가역성이 중요하다.

**RK4:** 한 단계에서 시작·중간·끝의 기울기를 네 번 계산해 가중 평균한다. 짧은 구간에서 일반적으로 정밀하지만 전통적인 RK4 자체는 심플렉틱 적분기는 아니다.

오일러는 전역 오차 차수 1차, Verlet은 2차, RK4는 4차인 대표 사례다. 단, 실제 수치오차는 시간간격, 초기조건, 시뮬레이션 기간에 따라 달라진다.

## 4. 무엇을 비교했는가?

모두 동일한 초기 상태와 총 적분시간 `2π`, 스텝수 160으로 통제했다.

평가 지표:

1. **최대 상대 에너지 드리프트:** 전체 과정에서 `|E(t)-E(0)|/|E(0)|`의 최대값.
2. **최대 상대 각운동량 드리프트:** `|h(t)-h(0)|/|h(0)|`의 최대값.
3. **종점 위치 오차:** 정확히 한 바퀴 후 시작점 `(1,0)`에서 얼마나 떨어졌는가.
4. **격자 세분화:** 스텝 수를 40→80→160→320으로 늘리면 오차가 어떻게 변하는가.

## 5. 실제 결과

| 적분 방법 | 최대 상대 에너지 드리프트 | 한 바퀴 후 위치 오차 |
|---|---:|---:|
| Euler | 0.26485 | 1.6745 |
| Velocity Verlet | 0.00000059317 | 0.0032279 |
| RK4 | 0.000000016305 | 0.00000041917 |

오일러의 에너지 상대오차 0.26485는 기준 에너지 절댓값의 약 26.5%만큼 차이가 발생한 순간이 있다는 뜻이다. 이는 중력이 바뀌었다는 발견이 아니라 수치 방식 문제다.

**이 실험에서 RK4는 가장 작은 단기 오차를 보인다.** 따라서 'Verlet은 언제나 RK4보다 정확하다'는 결론은 틀리다. Verlet의 장점은 오랫동안 보존되는 동역학의 기하 구조를 더 잘 다루는 데 있다. 한 바퀴만으로 장기 우수성을 입증하지는 못했다.

## 6. 파일과 코드의 연결

`orbitlab/physics.py`

- `State`: `(x, y, vx, vy)` 불변 데이터 클래스.
- `acceleration`: 가속도 `-μ r/r³` 계산.
- `energy`, `angular_momentum`: 물리적 불변량 계산.
- `euler_step`, `verlet_step`, `rk4_step`: 각각 한 시간 스텝 갱신.
- `integrate`: 선택한 방법을 여러 스텝 반복.
- `diagnostics`: 최종 상태 목록의 오차를 측정.

`orbitlab/run.py`: 세 방법을 같은 조건에서 실행, CSV와 두 차트 생성.

`tests/test_orbits.py`: 물리 초기조건, 잘못된 입력 처리, 원궤도 종점, 에너지·각운동량, 시간가역성 등 18개 테스트.

## 7. 직접 재현

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m orbitlab.run
python -m orbitlab.run --eccentricity 0.4 --out artifacts/eccentric
```

`artifacts/orbit_comparison.png`에서 실제 궤도 경로를 보고, `artifacts/convergence.png`에서 수치해석 방법과 스텝 수의 관계를 확인한다. CSV는 계산 결과 자체를 검토할 때 유용하다.

## 8. 왜 이런 접근을 선택했나?

- 물리법칙을 먼저 **검사 가능한 보존량**으로 정의해 코드 정확성을 평가했다.
- 복잡한 N-body를 바로 구현하지 않고 정확한 해를 잘 아는 케플러 원궤도로 시작해 오차 원인을 분리했다.
- 세 방법을 동일한 dt·총 시간으로 비교해 방법 차이를 보여줬다.
- 격자 세분화를 넣어 특정 dt 하나만 보고 결론내리는 오류를 줄였다.
- 결과 차트를 별도로 제공해 면접·블로그에서 원리와 결과를 설명할 수 있다.

## 9. 아직 증명되지 않은 것

실측 위성 궤도, n-body 안정성, 섭동 포함 정밀궤도 예측, 인공위성 조종, 우주 임무 안전성, 장기 심플렉틱 정확도, 실시간 제어 성능은 증명하지 않았다.

# 심화 면접 20문항

### Q01. 중력 가속도 식에 r³이 있는 이유는?

**답:** 벡터의 크기는 1/r²로 줄고 방향을 위치벡터로 표현하므로 r 벡터에 1/r³을 곱한다.

### Q02. 상태변수 네 개는?

**답:** 2D 위치 x,y와 속도 vx,vy다. 가속도는 위치에서 계산한다.

### Q03. 무차원 단위란 무엇인가?

**답:** 반지름·시간·중력 파라미터 등 기준 척도를 정해 단위가 제거된 수치로 만드는 것이다.

### Q04. 왜 원 궤도 에너지가 -0.5인가?

**답:** μ=r=v=1일 때 운동에너지 1/2, 위치에너지 -1이므로 합이 -1/2다.

### Q05. 오일러 적분법의 핵심 한계는?

**답:** 현재 기울기만 이용하는 1차 정확도로, 시간간격을 크게 잡으면 누적 오차가 커진다.

### Q06. Velocity Verlet의 갱신 순서는?

**답:** 현재 위치·속도·가속도로 새 위치를 만든 뒤, 새 위치 가속도를 계산하고 속도를 평균 가속도로 보정한다.

### Q07. RK4의 네 기울기는 왜 필요한가?

**답:** 한 시간 스텝 안에서 변화하는 기울기를 여러 지점에서 샘플링해 높은 차수의 국소 정확도를 얻기 위해서다.

### Q08. 이번 실험에서 어떤 방법의 종점오차가 가장 작나?

**답:** RK4다. 동일한 원 궤도·160 스텝 조건에서 약 4.19e-7이었다.

### Q09. Symplectic은 정확히 무슨 뜻인가?

**답:** 해밀토니안 동역학의 위상공간 심플렉틱 구조를 보존하는 적분방법의 성질이다. 단순히 매 스텝 에너지가 정확히 일치한다는 뜻은 아니다.

### Q10. Verlet은 에너지를 정확히 보존하나?

**답:** 일반적으로 정확한 물리 에너지를 매 스텝 정확히 보존하는 것은 아니며, 해당 보존계에서 장기 오차가 유계로 진동하는 성질을 기대할 수 있다.

### Q11. 한 바퀴만 실험하고 장기 안정성을 주장할 수 있나?

**답:** 없다. 장기 궤도 수천 회 및 여러 eccentricity·dt에서 검증해야 한다.

### Q12. 시간가역성 검사는 어떻게 하나?

**답:** 앞으로 적분한 후 속도를 반전시키고 같은 양의 시간만큼 다시 적분하면 초기 위치로 돌아오는지 측정한다.

### Q13. 각운동량이 보존되는 이유는?

**답:** 중심력은 위치벡터와 같은 방향이어서 중심에 대한 토크가 0이기 때문이다.

### Q14. grid refinement를 하는 이유는?

**답:** dt를 줄였을 때 오차가 줄어드는 경향과 기대 차수를 보면서 구현이 수렴하는지 확인한다.

### Q15. 오차 차수 4는 무슨 뜻인가?

**답:** 충분히 작은 dt에서 총 구간 전역 오차가 대체로 dt의 4제곱에 비례한다는 이론적 특징이다.

### Q16. 실제 위성 위치와 왜 비교할 수 없나?

**답:** SI 단위·초기 궤도 요소·섭동·관측 자료가 없고 단순 중심중력만 모델링했기 때문이다.

### Q17. RK4가 항상 Verlet보다 우수한가?

**답:** 아니다. 단기 종점 정확도는 RK4가 더 나을 수 있어도 장기 해밀토니안 구조 보존은 Verlet이 유리할 수 있다.

### Q18. 궤도 이심률을 0.4로 바꾸면 무엇이 달라지나?

**답:** 원궤도 대신 타원 궤도를 나타내며 가까운 지점과 먼 지점에서 속도와 가속도 크기가 달라진다.

### Q19. 이 프로젝트를 Physical AI로 연결하려면?

**답:** 동역학 모델에 상태추정, 제어입력, 센서오차, MPC, 시스템 식별 등을 추가해 실제 제어와 검증으로 확장한다.

### Q20. 최전선 연구로 확장 시 첫 비교 대상은?

**답:** 장기간 심플렉틱 적분, SciPy solve_ivp 적응 스텝, N-body 에너지 보존 및 실제 관측 궤도 오차를 비교한다.
